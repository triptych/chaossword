# loop
1. read and consider all the background documents such as background.md, plot.md, sensory_elements.md, and the rest of the files.
2. read the previous chapter if available to understand the context.
3. write the current chapter based on the information in the background documents and the previous chapter. Use the plot.md to understand what needs to happen in this chapter.
4. write the chapter in a way that is engaging and interesting to the reader.
5. make sure to keep the writing style consistent with the previous chapters.
6. when you are done writing the chapter, update the plot.md and check off the chapter as complete.
7. update the loop.md CURRENT_CHAPTER variable to the next chapter number.
